# ADR 012: CI funcional local y entrega recuperable por separado

**Estado:** Piloto `in_progress`, 6/8 tareas al corte.

**Contexto.** Lint, tipos, unitarias y build no comprobaban que la demo, el login y la importación funcionaran juntos contra servicios reales. El entorno local tropezó con el ejecutor de una migración y con orígenes distintos en el callback del correo.

**Decisión.** Probar el build de producción con Supabase y correo efímeros, datos sintéticos y un origen de navegador coherente. Para la migración en cuestión, ejecutar el SQL original en el contenedor descartable con su administrador y verificar propietarios; no relajar permisos. Exigir que todas las pruebas del piloto corran. Mantener despliegue y ensayo de recuperación como acciones separadas y autorizadas.

**Alternativa y costo.** Simular rutas críticas o declarar éxito con pruebas omitidas haría el piloto más barato pero borraría la evidencia buscada. El stack tarda más y depende de Docker y puertos libres. Se observaron 5/5 pruebas locales y un fallo deliberado al cambiar USD 20 por USD 21; todavía no se demostró el bloqueo en un PR ni se ensayó una recuperación remota. Recuperar código tampoco revierte datos.
